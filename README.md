# ProyectoSemestral_Movil
Descripción
Este proyecto tiene como objetivo crear una aplicación interactiva en Android Studio que permite a los usuarios realizar una dinámica de aprendizaje tipo "pareo", en la que deben asociar objetos con colores correspondientes. Además, la aplicación utiliza sensores de luz ambiental y pickup (Wakeup) para mejorar la experiencia del usuario.
Sensor de luz ambiental: Ajusta el brillo de la pantalla según el entorno, cambiando entre un tema claro u oscuro.
Sensor Pickup (Wakeup): Detecta cuando el dispositivo es levantado y enciende automáticamente la pantalla, facilitando la interacción del usuario.

Funcionalidades
1. Dinámica de Pareo
Los usuarios deben asociar correctamente los objetos con sus colores correspondientes.
La interfaz gráfica permite arrastrar los objetos hacia su color correspondiente.
Se valida si la asociación es correcta o incorrecta, con retroalimentación visual y sonora.

2. Animaciones
Retroalimentación Visual: Se aplican animaciones como un brillo o expansión cuando el usuario hace una acción correcta.


3. Sensores en Android
El proyecto incluye el uso de dos sensores para mejorar la experiencia del usuario:
Sensor de Luz Ambiental
Detecta el nivel de luz en el entorno y ajusta el brillo de la pantalla, o cambia el tema de la interfaz entre claro y oscuro según el ambiente.
Sensor Pickup (Wakeup)
La pantalla del dispositivo se enciende automáticamente cuando el dispositivo es levantado, lo que facilita la interacción con la aplicación sin necesidad de presionar botones.
